# 業務メモ

新しい仕事で覚えたことを、分類せずにその場でサッと記録するための、自分専用のメモアプリです。
スマホ（iPhone）での利用を前提にしています。

- **メモする**：開いたらすぐ書ける。「保存」を押すだけ（日時は自動で記録）
- **メモ一覧**：新しい順に表示。編集・削除・複数選択ができる
- **書き出し**：選んだメモを日時付きのテキストにまとめ、コピーまたは .txt ファイルで保存
- **整理済み**：ChatGPTなどで整理した文章を、自分で貼り付けて保存しておく場所
- **バックアップ／復元**：全データを1つのファイルに書き出し、あとで戻せる

> このアプリは、AIや外部サービスへ**自動でデータを送る機能を持っていません**。
> 書き出したテキストをどこに渡すかは、毎回あなた自身が判断します。

---

## 1. データはどこに保存されるの？

メモとノートは、**あなたのスマホの、そのブラウザの中（IndexedDB という保存場所）だけ**に保存されます。

- GitHub にも、公開に使うサーバーにも、**メモの内容は一切送られません**
- 公開されるのは「アプリの画面とプログラム」だけで、中身（メモ）は含まれません
- 同じアプリを別のスマホやパソコンで開いても、**データは共有されません**（端末ごとに別々）

### iPhone の注意点

- **Safari で開いたときと、ホーム画面に追加したアプリとでは、保存場所が別々です。**
  いつも同じ方（おすすめはホーム画面のアプリ）から使ってください。
- Safari のタブで開いて使う場合、しばらく（7日程度）開かないとデータが消されることがあります。
  **ホーム画面に追加して使う**と、この自動削除の対象外になり、消えにくくなります。

---

## 2. データが消える可能性があるケース（必ず読んでください）

次のようなときに、メモが**消えて戻らなくなる**ことがあります。

- Safari の「履歴とWebサイトデータを消去」をした
- 設定 → Safari → 詳細 → Webサイトデータ で、このサイトのデータを削除した
- ホーム画面のアプリのアイコンを削除した
- iPhone を初期化した・買い替えた・故障した
- iPhone の空き容量が極端に少なくなり、システムがデータを整理した
- 公開先のURL（アドレス）が変わった（別の場所扱いになり、前のデータが見えなくなる）

**対策はバックアップだけです。** 次の章の方法で、定期的に（例：週1回）書き出しておいてください。

---

## 3. バックアップと復元のやり方

### バックアップを書き出す

1. 「メモ一覧」→ 右上の「**バックアップ**」
2. 「**バックアップを書き出す**」を押す
3. `work-memo-backup-日付-時刻.json` というファイルができます
   - iPhone では、共有メニューやプレビューが出たら「**"ファイル"に保存**」を選び、保存先を決めます

> ⚠ **バックアップファイルには、すべてのメモとノートがそのまま読める形で入っています（暗号化なし）。**
> 会社のルールで認められた場所に保存し、他人と共有するフォルダ・社外のクラウドなどには置かないでください。
> また、**GitHub には絶対にアップロードしないでください**。

### バックアップから復元する

1. 「メモ一覧」→「バックアップ」→「**バックアップファイルを選ぶ**」
2. 保存しておいた `.json` ファイルを選ぶ
3. 「何件追加されるか」が表示されるので、確認して「OK」

復元は**「今のデータに追加する」方式**です。

- 今あるメモやノートが**消えたり上書きされたりすることはありません**
- すでに同じ内容があるものは、二重に追加されません
- 同じメモでも内容が変わっている場合は、今のものを残したまま、バックアップ側を**別のメモとして追加**します

## 4. GitHub への登録方法（初めての人向け）

GitHub は、プログラムのファイルを保管・公開できるサービスです。ここでは**ブラウザだけで**できる方法を説明します。

1. https://github.com でアカウントを作成してログイン
2. 右上の「＋」→「**New repository**」
3. 次のように入力して「**Create repository**」
   - Repository name：例 `work-memo`
   - 公開範囲：**Public**（無料で公開するには Public が必要です。
     公開されるのはアプリのプログラムだけで、あなたのメモは含まれません）
4. 作成された画面の「**uploading an existing file**」をクリック
5. この `work-memo` フォルダの**中身**（`index.html`、`css`、`js`、`icons` など）をまとめてドラッグ＆ドロップ
   - **バックアップファイル（.json）や書き出したテキスト（.txt）は入れないでください**
   - `tools` フォルダはアイコン作成用なので、入れても入れなくても構いません
6. 下の「**Commit changes**」を押す

> パソコンで `git` コマンドを使える人は、このフォルダで `git init` → `git add .` → `git commit` → `git push` でも同じです。
> `.gitignore` により、バックアップや書き出しファイルは自動で除外されます（ブラウザからのアップロードでは効かないので注意）。

## 5. 公開方法（GitHub Pages を使う場合）

GitHub Pages を使うと、無料で **https:// のアドレス**でアプリを公開できます。

1. 作成したリポジトリの画面で「**Settings**」→ 左メニューの「**Pages**」
2. 「Build and deployment」の Source を「**Deploy from a branch**」
3. Branch を「**main**」、フォルダを「**/ (root)**」にして「**Save**」
4. 1〜2分待つと、画面上部に公開アドレスが表示されます
   例：`https://あなたのユーザー名.github.io/work-memo/`
5. スマホの Safari でそのアドレスを開けば使えます

### ほかの静的ホスティングでも使えます

このアプリはサーバー側の処理が不要な「ファイルを置くだけ」のアプリです。
Cloudflare Pages、Netlify などでも、このフォルダの中身をそのままアップロードすれば動きます（**https で公開されること**が条件です）。

### アプリを更新して公開し直すとき

`sw.js` の中の `CACHE_NAME = 'work-memo-v1'` の数字を1つ上げて（`v2` など）からアップロードしてください。
こうしないと、スマホに残った古いアプリが表示され続けることがあります。
更新後は、アプリを一度閉じて開き直すと新しい版になります。

## 6. iPhone のホーム画面への追加方法

1. **Safari** で公開アドレスを開く（Chrome など他のブラウザではなく Safari を使ってください）
2. 画面下の **共有ボタン**（四角から上向き矢印が出ているアイコン）をタップ
3. 「**ホーム画面に追加**」をタップ（見つからなければメニューを下にスクロール）
4. 名前が「業務メモ」になっているのを確認して「**追加**」

ホーム画面のアイコンから開くと、アプリのように全画面で使えます。
一度開いておけば、**電波のない場所でも**開いて、メモの記録・閲覧ができます。

> 前述のとおり、Safari で開いていたときのメモは、ホーム画面のアプリには引き継がれません。
> 移したい場合は、Safari 側でバックアップを書き出し、ホーム画面のアプリ側で復元してください。

---

## 7. 使い方のコツ

- 書いている途中でアプリを閉じても、**書きかけの文章は自動で残ります**（保存ボタンを押すまでは一覧には出ません）
- 一覧のメモ本文をタップすると、長いメモを全文表示／折りたたみできます
- 書き出し画面のプレビューは直接書き換えられます。**社名や個人名を伏せてからコピー**する使い方ができます（元のメモは変わりません）
- パソコンのブラウザでは、`⌘ + Enter`（Windows は `Ctrl + Enter`）でも保存できます

---

## 8. 安全のための仕組み（技術的な説明）

- **外部通信の禁止**：`index.html` の Content-Security-Policy で `connect-src 'none'` を指定しています。
  万一プログラムに通信処理が紛れ込んでも、ブラウザがページからの通信（fetch / XHR / WebSocket / sendBeacon など）を遮断します。
  読み込むのは同じ公開元のファイルだけで、外部のフォント・CDN・解析ツールは使っていません。
- **通信が発生する唯一の場面**：アプリ本体のファイル（HTML / CSS / JS / アイコン / manifest / `sw.js`）を、公開元から取得するときだけです。
  これはアプリを開く・更新するときの通常の読み込みで、**メモやノートの内容は一切含まれません**。
  オフライン対応用の `sw.js` も、同じ公開元のファイルを取得・保存するだけです。
- **ログイン・アクセス解析・AI API・外部DB・クラウド保存は使っていません。**
- 入力した文字は画面にそのまま「文字」として表示し、HTMLとして解釈しません（悪意ある文字列を貼り付けても動作しません）。

## ファイル構成

```
index.html            画面
css/style.css         見た目
js/db.js              IndexedDB への保存・読み込み
js/app.js             アプリの動き
sw.js                 オフライン対応（アプリ本体のキャッシュ）
manifest.webmanifest  ホーム画面に追加するための設定
icons/                アイコン画像
tools/make-icons.py   アイコン画像を作り直すためのスクリプト（公開には不要）
```

## パソコンで動作確認する方法

このフォルダで次を実行し、ブラウザで `http://localhost:8440` を開きます（`localhost` は https でなくても動作します）。

```bash
python3 -m http.server 8440
```
